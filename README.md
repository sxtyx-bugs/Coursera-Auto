## ⚡ Quick Start & Installation

1. Open `chrome://extensions/` in Google Chrome or any Chromium browser.
2. Enable **Developer mode** via the toggle in the top-right corner.
3. Click **Load unpacked** and select this directory (`satuautomates`).
4. Pin **Coursera Assistant** to your browser toolbar.
5. Navigate to any course or quiz on [Coursera](https://www.coursera.org/learn).

## 🛠️ Features & Controls

| Feature | Action | Description |
| :--- | :--- | :--- |
| **Solve Active Quiz** | `quiz` | Solves the currently open quiz attempt using Gemini AI and selects correct answers with on-page toast feedback. |
| **Auto-Solve on Open** | `autoQuiz` | Hardware-style toggle that automatically triggers the quiz solver whenever an `/attempt` page is opened. |
| **Course Progression** | `bypass` | One-click engine to mark eligible lecture videos, readings, and discussion prompts as completed. |
| **Coach Dialogue** | `dialogue` | Auto-advances interactive multi-turn Socratic Coach dialogue widgets. |
| **Gemini Engine Config** | `key` / `model` | Configurable model selector (`gemini-2.5-flash`, `gemini-2.0-flash`, `gemini-1.5-flash`, or `gemini-1.5-pro`) and local API key storage. |

## 🎨 Design Philosophy: White Skeuomorphism
 
- **White Skeuomorphic Aesthetic:** Architectural studio whites, debossed inset wells, machined specular bevels, and crisp monochrome contrast.
- **Physical Tactile Controls:** Recessed input wells, specular highlights, and active depressed button states with realistic depth.
- **Immediate Inline Feedback:** The popup window remains open and displays active status without closing prematurely.
- **Non-Intrusive In-Page Notifications:** Uses Coursera in-page toast banners to confirm real-time solver execution.
